# 💫 About Me:
# Hi, I am Alan Tseng 👋

I am a student in the **Department of Computer Science and Information Engineering** at **National Taipei University**.

### 🎓 Senior Project
**Project Title:** Portable Real-Time Muscle Fatigue Quantification System Using AI and Near-Infrared Spectroscopy (NIRS)  
**Description:** Developed a real-time muscle fatigue quantification system integrating a wearable NIRS sensor with deep learning models.

---

## 🛠️ Hardware Architecture & Embedded System Integration

* **Hardware Design:** Responsible for the design and fabrication of the wearable NIRS sensor, including circuit architecture planning based on system requirements.
* **Environment Setup:** Established the initial runtime environment for **Luckfox Pico Mini** (including GPIO/I2C driver testing and package deployment).
* **Firmware & Data Processing:** Implemented hardware drivers, edge-side real-time data acquisition, signal processing, and output using **Python**.
* **System Stability:** Configured the **Linux** environment and managed dependencies using **Systemd** auto-start services to ensure stable, automated operation upon boot.

---

## 🚀 Research Achievements & Recognition

* **Performance:** Increased classification accuracy to nearly **90%** and successfully deployed the model onto portable edge devices for independent real-time interpretation.
* **Grant:** Awarded the **NSTC Research Grant for University Students** (114th Academic Year).
* **Publication:** Research findings submitted to the **IEEE Sensors Journal**.
* **Patent:** Completed the application for an **Invention Patent**.
* **Exhibitions:**
